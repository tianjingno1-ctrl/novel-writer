# 第1章

【第1章】我，恶毒女配，不干了

屋里黑漆漆的，林晚也没点灯，摸黑坐到床边，脱了鞋，盘腿坐好。

系统还是沉默。

她等了片刻，终于忍不住在心里喊了一声：“在不在？给个话。”

【在。】

“刚才那事儿，算我过线了吗？”林晚老实不客气地问，“我确实按你说的没碰主线，但你也没说不能顺便教训个炮灰。”

系统又是一阵沉默，像是在运算。

【任务完成度：第一阶段已达标。未触发警告。】

林晚满意地往后一躺，倒在柔软的锦被上：“那就行。”

她盯着头顶的帐幔，暗红色绣着缠枝莲纹，配着古色古香的床架，让她有一瞬间的恍惚。

上辈子她住在三十楼的公寓里，落地窗外是霓虹灯海，睡觉前最后一件事是关掉手机屏幕。

现在呢？她连一根充电线都找不到。

算了。

既来之则安之。

这个世界的林晚，京城首辅嫡女，长得不错，家世够硬，被赐婚给镇北王顾时寒。

她上辈子在职场熬了八年，拼到项目经理，结果体检报告出来的时候直接瘫在走廊里。

现在老天让她重活一回，还附带一个系统——虽然这系统让她穿成了恶毒女配。

但她不打算按剧本走。

炮灰是蠢货才当的。

她只要老老实实苟到剧情结束，等男女主he，她就可以拿着首辅嫡女的身份牌安享晚年了。

多好。

第二天一早，春兰端着铜盆推门进来，看见林晚已经自己穿好了衣服，正站在铜镜前系腰封。

“小、小姐？”春兰吓了一跳，“您怎么自己动手了？这些该奴婢来做——”

“我又不缺胳膊少腿，自己穿个衣服还能累死？”林晚对着铜镜左右转了转，随手把一根白玉簪插进发髻，“走，吃早饭去。”

春兰愣愣地看着她，像是看到了什么怪物。

“小姐，您以前从来不自己动手的……”

“从今天开始改了。”

林晚跨出门槛，清晨的阳光洒在青石板路上，院子里的海棠花开得正好，粉白相间，层层叠叠的。

她深吸一口气，觉得空气都甜。

——虽然古代这生活质量不行，但环境是真的好。

到了正厅，桌上已经摆好了早膳。

一碗清粥，几碟小菜，一笼热气腾腾的小笼包。

林晚坐下来，夹起一个包子咬了一口，汤汁淌出来，烫得她直吸气，但她没舍得吐，硬是嚼了下去。

春兰站在旁边，忍不住小声提醒：“小姐您慢点，小心烫……”

“没事没事。”林晚又夹了一个，沾了点醋，塞进嘴里，含含糊糊地说，“好吃，真好吃。”

上辈子那些速冻包子跟这个简直没法比。

吃到第三个包子的时候，外头传来脚步声，一个身穿青色比甲的大丫鬟走了进来，脸色不太好看：“小姐，老夫人请您过去一趟。”

林晚抬头，嚼完嘴里的包子，擦了擦手：“什么事？”

大丫鬟低着头：“奴婢不知，老夫人只说让您快些去。”

林晚心里有数了。

昨天赵婉仪那事儿，八成已经传到老太太耳朵里了。

原著里的林晚是老太太最宠的嫡孙女，所以才能在京中横行无忌。

但现在这具壳子里的人换了，她可不想一上来就把最大靠山给得罪了。

“行，我吃完这口就去。”她慢悠悠地把碗里的粥喝干净，又拿帕子擦了擦嘴角，这才站起来，“走吧。”

林老夫人住在后院的正堂里，穿了一身暗红色的褙子，头发梳得一丝不苟，端坐在罗汉床上，手里捻着一串佛珠，面色不冷不热。

旁边站着一个妇人，正是林府的大夫人——林晚的嫡母。

这位大夫人不是林晚的生母，所以对她向来是表面客气，骨子里巴不得她出点什么事。

林晚一进门，先规规矩矩地福了一礼：“孙女见过祖母。”

老夫人捻佛珠的手没停，目光落在她脸上：“昨儿在赵府的宴会上，你又闯祸了？”

林晚站直了，神色坦然：“回祖母的话，孙女没有闯祸。”

“没有？”大夫人接过话头，声音尖锐，“我听说你当众指认赵家小姐偷了苏棠的玉佩，还逼得赵小姐哭着跑了——这不叫闯祸？赵家也不是寻常人家，你让老太太怎么跟他们交代？”

林晚转头看向大夫人，笑了一下：“母亲别急，容孙女说句话。”

她转回来，面对着老夫人，语气不卑不亢：“祖母，昨天的情况是这样的。那枚玉佩是苏棠的东西，赵婉仪不知道从哪儿拿到了手里，非说是别人送的。孙女不过是当着众人的面，请她确认了一下玉佩的来历和刻字。她自己答不上来，丢了脸，那是她自己的事，跟孙女没关系。”

“你请她确认？”大夫人冷笑，“你那也叫请？分明是当着所有人的面把她架在火上烤！”

林晚耸了耸肩：“母亲若非要这么说，那孙女也没办法。难道孙女应该看着她拿了别人的东西，还当众说是别人送她的？那样岂不是纵容偷盗之风？”

大夫人被她噎得说不出话来。

老夫人捻佛珠的动作停了。

她盯着林晚看了好一会儿，忽然问：“你以前不是最见不得苏棠的吗？怎么这回反倒帮起她来了？”

林晚笑了笑：“孙女帮的不是苏棠，孙女帮的是道理。谁对谁错，心里有数，不能因为不喜欢一个人就眼睁睁看着她被冤枉。”

老夫人的目光在她脸上停留了很久，像是想从她的表情里找到一点以前那个飞扬跋扈的林晚的影子。

但没找到。

眼前的林晚，眉眼还是那双眉眼，骨子里却像是换了个人。

“行了，”老夫人最终挥了挥手，“这件事我知道了。赵家那边，我会让人去说，你不必管了。”

“多谢祖母。”林晚再次福了一礼。

“去吧。”

林晚转身往外走，走出门口的时候，正好碰上一个穿着绛红色长衫的身影走进来。

两个人差点撞上。

林晚抬起头，对上了一双幽深的眼睛。

顾时寒。

他怎么会在这里？

“王爷。”林晚退开半步，微微低头，语气平淡，“不知王爷大驾光临，有失远迎。”

顾时寒的目光从她脸上扫过，掠过她嘴角还沾着的一点点醋渍，没有移开视线。

他的嘴角微微弯了一下，很淡，像是一闪而过的错觉。

“从老太太那儿出来？”他问。

“是。”

“正好。”顾时寒侧过身，“本王也要去见老太太，一道走几步？”

林晚本能地想要拒绝，但话到嘴边又咽了回去——她现在没有得罪男主的本钱。

“王爷请。”

两个人并肩走在回廊里，春兰和顾时寒的近卫都远远跟在后面，不敢靠近。

走了几步，顾时寒忽然开口：“听说你昨天立功了。”

林晚愣了一下：“什么功？”

“给清白了多年的人讨回公道，”他偏头看她，“我这个未婚妻，什么时候变得这么深明大义了？”

林晚脚步微微一顿，随即恢复如常：“王爷说笑了，我不过是做了一个人该做的事。”

“你以前不是一个会做该做的事的人。”

“以前是以前，现在是现在。”

她停下脚步，转过头来看着他，风吹起她额前的碎发，露出她清亮平静的眼睛。

“王爷，人要是活了一辈子都不长进，那还不如白活了，您说是不是？”

顾时寒没有说话。

他就那么看着她，眼睛里有什么东西在慢慢变深。

良久，他低声说了一句：“你以前不是这样的。”

林晚笑了一下，转身往前走，声音散在风里：“不，王爷您错了。”

“我从来都是这样的。只是您以前没看见罢了。”
