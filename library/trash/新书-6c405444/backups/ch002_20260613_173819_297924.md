# 第2章

【第2章】限量黑卡背后

中年男人走进餐厅时，所有人都下意识站了起来——除了苏晚宁。

她还坐着，手里的筷子夹了最后一根青菜，嚼完，放下筷子。

“苏小姐，”男人微微欠身，双手递上平板电脑，“我是华商银行私人银行部总经理，周明远。这张卡的系统激活需要您的指纹确认。”

“嗯。”苏晚宁抬手，食指按在屏幕指纹区。

平板“叮”一声，绿色的确认图标亮起。

周明远收回平板，转向顾明哲：“顾先生，这张卡的信用额度是人民币一亿八千万元，单日取现上限五百万。如果您需要周转，苏小姐已授权我将这笔资金划入您指定的账户。”

顾明哲的脸色变了。

一亿八千万——不是她说的一个亿，多出来的八千万连他自己都不知道。

“不可能……”顾婷婷的声音发颤，“她怎么可能有这么多钱？她就是个家庭主妇，三年来连门都没怎么出过！”

周明远笑了笑，语气客气但不卑不亢：“苏小姐是我们银行的顶级黑卡客户之一，这张卡已持有五年。按照银行保密协议，详细信息恕不能透露。”

“五年？”赵美兰的脸彻底垮了，瞪着苏晚宁，“五年前你还没嫁进我们家！你哪来的钱？”

苏晚宁端起茶杯，吹了吹热气，没接话。

陆薇的脸色从白变成灰，她干笑了一声：“顾总，你太太……挺有意思的。”

顾明哲没理她，死死盯着苏晚宁：“你到底是谁？”

苏晚宁放下茶杯，杯底磕在桌面上，发出一声清脆的响。

“你娶我的时候，没查过我的背景，现在问这个问题，是不是晚了点？”

顾明哲哑口无言。

三年前他娶苏晚宁，唯一知道他底细的只有她自己——她父母双亡，孤身一人，在广告公司做设计。他以为她只是个普通到不能再普通的女孩。

现在她告诉他，她有一张五年历史的黑卡。

五年。

也就是说，他们结婚前，她就已经拥有这笔财富。

“晚宁，”顾明哲的声音软下来，“你可以告诉我的。”

“告诉你什么？”苏晚宁抬眼看他，眼神平静得像深夜的水面，“告诉你我母亲留给我的信托基金有好几亿？告诉你我十八岁就开始做天使投资？告诉你我只是想过平凡日子，可你们家连口热饭都不让我吃安稳？”

顾明哲的嘴唇动了动，一个字都说不出来。

周明远适时开口：“苏小姐，您还有别的吩咐吗？”

“没有了，你回去吧。”

周明远点头，看了眼手表，又补了一句：“苏小姐，您名下的另外三张附属卡也需要激活吗？”

另外三张。

附属卡。

全场的空气像被抽走了。

赵美兰扶着桌子才没摔倒。

苏晚宁摇了摇头：“不用，那几张是留给我未来孩子的。”

说完，她拿起手机，拨了一个号。

电话接通，对面传来一个恭敬的声音：“苏总。”

“把我名下恒盛集团的股份，全部转到我自己名下。”

“您指的是减持还是直接划转？”

“直接划转，”苏晚宁语气平淡，“我要实控人身份变更。”

电话那头沉默了两秒：“苏总，您确定？恒盛集团是您母亲留下的核心资产，您一旦实控，根据证券法规定，当晚就必须公告。”

“那就公告。”

她挂断电话。

餐厅里安静得能听见汤凉下来的声音。

顾婷婷忽然疯了一样地掏出手机，手指哆嗦着打开新闻APP。

屏幕最上方，一条绿色加粗的推送赫然跳出来：

【突发】恒盛集团实控人变更，神秘女富豪苏晚宁持股比例升至51%，正式入主董事会。

顾婷婷的手机“啪”地掉在地上，屏幕碎了。

“恒盛……集团？”她的声音像被人掐住了喉咙，“那个市值三百亿的恒盛集团？”

苏晚宁站起来，拿起桌上的黑卡，装回包里。

她没看任何人，只对顾明哲说了一句：“协议书签完，律师会联系你。”

“晚宁——”顾明哲想抓住她的手腕。

她侧身避开。

动作很轻，就像三年里避开了无数次。

“对了，”她走到门口，回头看了一眼这一家子——赵美兰瘫在椅子上，顾婷婷蹲在地上捡手机，陆薇不知什么时候悄悄退到了墙角，“你们家的真丝裙子我熨好了，挂在衣柜里。下次，你自己熨。”

说完，她推门走了出去。

夜风迎面吹来，她深深吸了口气。

手机响了。

是刚才那个电话。

“苏总，公告已经发出去了，媒体开始联系公司。”对面顿了顿，“您今晚要出面吗？”

苏晚宁站定，回头看了一眼身后那扇还在晃动的门。

“不出面。”她说，“让他们猜。”

她挂断电话，沿着路灯亮起的方向慢慢走远。

身后，餐厅里传来顾婷婷尖锐的哭喊声：“哥！你快去追她啊！她怎么能走——”

然后是赵美兰的声音：“刚才那张卡……到底是真的还是假的？”

没人回答她。

连周明远都走了。

桌上只剩半桌凉透的菜，和一张碎屏的手机。
