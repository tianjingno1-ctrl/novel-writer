## 1. 快速开始

### 1.1 环境准备

项目目录结构：

```
novel_writer/
├── .env              ← 填写 API Key（见下）
├── main.py
├── web_app.py
├── config.py
├── novel_data.py
├── file_utils.py
└── data/             ← 运行后自动生成
    ├── chapters/
    ├── backups/
    ├── codex/
    └── *.md
```

在项目根目录创建 `.env` 文件：

```env
KIE_API_KEY=你的_KIE_API_Key
DEEPSEEK_API_KEY=你的_DeepSeek_API_Key
```

> ⚠️ 注意：如果文件名误写为 `.evn`，启动时终端会有提示，建议重命名为 `.env`。

### 1.2 启动服务

```bash
python web_app.py
# 或双击 启动web.bat
```

浏览器访问 `http://127.0.0.1:8765`（启动后通常会自动打开）。

> **本地单人使用**：Web 进程内共享同一份写作会话；多标签会互相干扰。服务无鉴权，请勿对公网暴露。
顶部红色横幅消失 = API Key 配置成功。

### 1.3 第一次使用推荐流程

```
1. Write 模式 → 全局文件 → 编辑 world.md、characters.md，写好基础设定
2. Plan 模式  → 新建章节 → 添加场景 → 填写 Scene Beat
3. Write 模式 → 选择章节 → 写开头或粘贴素材（约 2 秒自动保存）
4. 写书对话   → 发送「续写」指令 → AI 流式逐字返回正文
5. 写书对话   → 「生成概述」/「连续性检查」（写完章后按需点击）
6. 统计 模式  → 查看字数、章节数、累计 API 费用
```

### 1.4 命令行 vs Web 面板对照

| 原 CLI 操作 | Web 面板操作 | 说明 |
|-------------|--------------|------|
| 编辑 `world.md` | Write → 全局文件 → 世界观 world.md | 直接编辑保存 |
| 编辑 `characters.md` | Write → 全局文件 → 人物总表 characters.md | 直接编辑保存 |
| 手动创建 `ch001.md` | Plan → 「新建章节」 | 自动编号，无需手建文件 |
| `/summary` | **写书对话** → 「生成概述」 | 追加到 summaries.md |
| `/check` | **写书对话** → 「连续性检查」 | 对照设定查矛盾 |
| `/patch 内容` | 全局文件末尾追加，或 **Codex 新建条目**（推荐） | Web 无专用追加按钮，见 §3.2 |

> 「统计」模式仅展示字数与费用，**不包含**生成概述/检查按钮（这两个在写书对话输入框下方）。

## 3. 五大模式详解

### 3.1 Plan 模式（规划）

用于规划章节结构，在写正文之前先搭框架。

| 操作 | 方法 |
|------|------|
| 新建章节 | 顶部「新建章节」按钮（弹出确认框，防误触） |
| 重命名章节 | 「重命名」按钮 → 输入新标题 |
| 添加场景 | 「+ 添加场景」按钮，输入场景标题（**不能为空**） |
| 编辑 Scene Beat | 点击场景卡片 → 右侧面板编辑 Beat 文本 |
| 标记完成 | 场景卡片标题旁的复选框 |
| 调整顺序 | 拖拽场景卡片上下移动 |

> 💡 **Scene Beat** 是场景的写作提纲。填写后，Chat 模式会自动将 Beat 注入给 AI，引导生成方向。

---

### 3.2 Write 模式（写作）

主编辑器，用于直接编写或查看章节正文。

- **切换章节**：左侧章节列表点击，当前章节高亮显示
- **编辑正文**：直接在编辑器中输入
- **保存**：点击「保存」按钮，或停止输入约 **2 秒**后自动保存
- **字数统计**：底部右侧实时显示（不含空白字符）

> 💡 切换章节前会自动保存；停止输入约 2 秒也会自动保存。

#### 追加人物设定（等同 `/patch`）

Web 没有单独的「追加 patch」按钮。推荐两种方式：

1. **设定库 Codex（推荐）**：侧边栏新建人物/地点条目，勾选后注入写书对话，天然避免误改旧内容。
2. **全局文件 → 人物总表**：滚到**文件末尾**手动追加新段落，**不要修改上方已有设定**（与 CLI `/patch` 只增不改一致）。

---

### 3.3 Chat 模式（写书对话）⭐ SSE 流式输出

与 AI 协作写作的核心模式。本版本已实现 **SSE 流式输出**，AI 回复逐字实时显示在气泡中。

#### 发送指令

1. 在底部输入框输入写作指令，例如：
   - `续写500字，保持紧张感`
   - `润色上一段，减少重复词`
   - `这个场景的魔法系统合理吗？`
2. 点击「发送」或按 `Enter`
3. AI 开始流式返回，气泡逐字填充，完成后自动刷新状态栏费用

#### 指令类型识别

| 指令类型 | AI 输出格式 | 用途 |
|----------|------------|------|
| 续写 / 扩写 / 润色 / 修改 | 纯正文 | 可直接复制到编辑器 |
| 提问 / 讨论 | `[讨论]` / `[问答]` / `[建议]` 开头 | 对话性回复，不算正文 |

#### 辅助按钮（等同 CLI 命令）

输入框下方还有两个按钮（使用辅助模型 DeepSeek，省额度）：

| 按钮 | 等同 CLI | 作用 |
|------|----------|------|
| 生成概述 | `/summary` | 为最新章节生成 150–300 字概述，追加到 summaries.md |
| 连续性检查 | `/check` | 对照世界观、人物、概述，列出最新章矛盾点 |

#### 注意事项

- 发送中按钮变为「生成中…」并禁用，**流传输全程保持锁定**，防止并发乱序
- 如果已有请求进行中，再次点击会弹出「请等待当前请求完成」
- **首字节超时 90 秒**；收到数据后改为 **180 秒无新内容**才超时（适合长文续写）
- 连接异常或后端报错会 toast 提示，并显示在错误栏
- 流式完成后 `done` 事件携带本次费用，底栏立即更新
- 清空对话记录前会弹出**确认框**，防止误清

#### 场景联动

在 Plan 模式中选中某个场景后，Chat 会自动携带该场景的 Beat 作为上下文注入 AI。

---

### 3.4 Free 模式（自由聊天）

与 AI 进行与写作无关的对话，**不注入任何写作上下文**，适合头脑风暴、设定讨论、闲聊。

- 默认使用 **DeepSeek**（省钱）
- 在自由聊界面顶部的模型下拉框切换提供商（与写书主力模型独立）
- 对话历史独立保存（`free_chat.json`），不影响写书对话
- 最多保留最近 **20 轮**对话（可在 `config.py` 中调整 `FREE_CHAT_CONTEXT_TURNS`）

---

### 3.5 统计模式

查看创作进度与 API 费用，**不含**写作或检查功能。

| 内容 | 说明 |
|------|------|
| 总字数 | 全稿字符数（不含空白） |
| 章节 / 场景数 | 正文文件数与 Plan 场景数 |
| Codex / 概述数 | 设定条目与已生成概述章数 |
| API 费用 | 累计预估费用 |
| 各章字数 | 分章统计列表 |

> 💡 生成概述、连续性检查请在 **写书对话** 模式使用（见 §3.3）。

## 4. 侧边栏功能

### 4.1 设定库 Codex

结构化管理人物、地点、规则等设定条目，每条目独立存为 JSON 文件。

| 操作 | 方法 |
|------|------|
| 新建条目 | 侧边栏右上角「+」按钮 |
| 编辑条目 | 点击条目名称 |
| 勾选注入 | 勾选复选框 → 该条目内容自动注入 Chat 上下文 |
| 搜索 | 顶部搜索框实时过滤 |

> ⚠️ 勾选 Codex 条目后，Chat 模式会**优先**使用 Codex 内容替代 `characters.md` 注入 AI。
> 适合只注入「本章相关人物」，减少无关 token 消耗。

---

### 4.2 写书记录（Chats）

显示当前写书对话的历史消息列表（每条预览最近 80 字）。

- 仅在 Write / Chat 模式下可见
- 用于回顾 AI 之前的输出，不可直接编辑

---

### 4.3 全局文件（Global）

直接在浏览器中编辑以下核心设定文件：

| 文件 | 用途 |
|------|------|
| `world.md` | 世界观、魔法体系、地图等（几乎不变） |
| `characters.md` | 主要人物初始设定（只追加，不修改） |
| `char_current.md` | 人物当前状态（可随章节更新） |
| `summaries.md` | 章节概述汇总（写书对话「生成概述」自动追加） |
| `plot_threads.md` | 伏笔与线索清单（手动维护） |

> 💡 编辑后点击「保存」，修改立即生效于下一次 AI 请求。

---

### 4.4 场景列表（Scenes）

仅在 Plan 模式下显示，列出当前章节的所有场景，点击可快速定位。

## 6. AI 提供商说明

| 提供商 | 标识 | 模型 | 适用场景 | 费用参考 |
|--------|------|------|----------|----------|
| kie.ai Claude | `kie` | claude-sonnet-4-6 | 主力写作、润色、多轮对话 | 较高，支持 Prompt Cache |
| DeepSeek | `deepseek` | deepseek-chat | 概述生成、连续性检查、自由聊天 | 极低 |

### Prompt Cache（仅 kie/Claude）

Claude 支持缓存世界观、人物设定、章节概述三层内容（TTL 1小时）。
底部状态栏会显示 `cache 命中 N` 或 `cache 写入`。
**首次请求写入缓存，后续请求命中缓存可大幅降低费用。**

## 7. 上下文策略说明

在设置中可切换 `上下文模式`（`CONTEXT_MODE`）：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| `beats` | 注入当前场景 Beat + 相关 Codex | **推荐默认**，精准控制每场景内容 |
| `summaries` | 注入章节概述历史 | 长篇连贯性要求高时 |
| `turns` | 仅保留最近 N 轮对话 | 轻量快速，省 token |
| `codex` | 强制使用 Codex 条目替代人物设定 | 已精细维护 Codex 时 |

> 💡 `beats` 模式下，Scene Beat 越详细，AI 生成的内容越贴合预期。

## 8. 备份与数据安全

### 自动备份机制

每次写入文件前自动备份到 `data/backups/` 目录：

- 备份文件名格式：`{原文件名}_{YYYYMMDD_HHMMSS}{扩展名}`
- **每个文件最多保留 10 份**备份，超出自动删除最旧的
- 覆盖范围：章节文件、plan.json、所有全局 .md 文件、Codex 条目

### 手动恢复

1. 进入 `data/backups/` 目录
2. 找到对应文件名和时间戳的备份
3. 复制到原路径覆盖即可

### 重要提示

- `data/` 目录包含所有创作数据，**定期手动备份整个 data 目录到外部存储**
- 程序退出时会自动保存对话记录到 `data/session_autosave.json`

## 9. 常见问题 FAQ

**Q：顶部一直显示红色横幅「API Key 未配置」？**
A：检查 `.env` 文件是否存在于项目根目录，Key 是否填写正确（不含多余空格或引号）。

**Q：发送后长时间没有响应？**
A：写书流式：90 秒内无任何数据会提示连接超时；开始输出后若 180 秒无新内容会提示生成超时。概述/检查等普通请求仍为 120 秒总超时。

**Q：流式输出中途停止？**
A：多为网络抖动、API Key 失效或服务端报错。已生成部分会保留在对话记录中，可刷新后查看并补充指令。

**Q：切换章节后编辑器内容丢失？**
A：切换章节前会自动保存；停止输入约 2 秒也会自动保存。若仍丢失，检查 `data/backups/` 恢复备份。

**Q：Codex 勾选了但 AI 好像没用到？**
A：确认上下文模式为 `beats` 或 `codex`，且勾选的条目内容不为空。

**Q：费用统计不准确？**
A：费用为**预估值**，基于 token 数与 `prices.json`（或内置）单价计算；详细记录见 `cost_log.jsonl`。实际账单以提供商后台为准。

**Q：AI 误把讨论写进章节了？**
A：Chat 模式点「撤销写入」（等同 CLI `/undo`），或从 `data/backups/` 恢复章节备份。

**Q：想重置对话历史重新开始？**
A：Chat 模式底部「清空记录」按钮（会弹出确认框）。注意清空后无法恢复。

**Q：如何只让 AI 知道本章相关人物，减少 token？**
A：在 Codex 中为本章人物创建条目并勾选，AI 会只使用勾选的条目而非整个 characters.md。
