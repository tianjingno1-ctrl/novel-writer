## 1. 快速开始

### 1.1 环境准备

项目目录结构：

```
novel_writer/
├── .env              ← 填写 API Key（见下）
├── main.py
├── web_app.py
├── config.py
├── novel_data.py
├── file_utils.py
└── data/             ← 运行后自动生成
    ├── chapters/
    ├── backups/
    ├── codex/
    └── *.md
```

在项目根目录创建 `.env` 文件：

```env
KIE_API_KEY=你的_KIE_API_Key
DEEPSEEK_API_KEY=你的_DeepSeek_API_Key
```

> ⚠️ 注意：如果文件名误写为 `.evn`，启动时终端会有提示，建议重命名为 `.env`。

### 1.2 启动服务

```bash
python web_app.py
# 或双击 启动web.bat
```

浏览器访问 `http://127.0.0.1:8765`（启动后通常会自动打开）。

> **本地单人使用**：Web 进程内共享同一份写作会话；多标签会互相干扰。服务无鉴权，请勿对公网暴露。
顶部红色横幅消失 = API Key 配置成功。

### 1.3 第一次使用（简版）

完整步骤与每步目的见 **[§1.5 顺序写作手册](#15-顺序写作手册)**。极简路径：

```
设定(world/人物) → 规划(章节+Beat) → 写正文 → 写书对话续写 → 生成概述 → 按需检查
```

### 1.5 顺序写作手册

按下面顺序做，**不要跳步**。每一行都写了**在界面上具体点哪里**；最右列是「为什么要做」。

#### 先认界面（后面步骤都按这个叫法）

```
顶栏：[规划] [写作] [写书对话] [自由聊] [统计]  ……右侧齿轮⚙️
左侧：标签页（随模式变） + 搜索框 + 蓝色 [+]
主区：中间大工作区（编辑器 / 场景看板 / 对话气泡）
底栏：左侧统计信息，右侧字数 pill
```

| 模式 | 顶栏点 | 左侧边栏会出现的标签 |
|------|--------|----------------------|
| 写作 | **写作** | **设定库** · **写书记录** · **全局文件** |
| 规划 | **规划** | **场景** |
| 写书对话 | **写书对话** | **写书记录** · **设定库** |
| 自由聊 | **自由聊** | **聊天记录** |
| 统计 | **统计** | （无侧边栏） |

#### 阶段 A：搭地基（只做一次，或开新书时做）

> **不必先建章节**。此阶段只动设定，主区显示编辑器即可，不会出现「+ 创建第一章」挡路。

| 步骤 | 面板操作（从上到下点） | 为了什么 |
|------|------------------------|----------|
| **A1** 世界观 | ① 顶栏点 **「写作」** → ② 左侧点标签 **「全局文件」** → ③ 列表点 **「世界观 world.md」** → ④ 主区大文本框里写设定 → ⑤ 主区右上点蓝色 **「保存」** → ⑥ 确认框点 **确定** | 世界观是 AI 的「物理定律」。对应 Prompt Cache **第 ① 层**。全局文件**不会自动保存**，必须点保存。 |
| **A2** 人物总表 | 同上 ①②，③ 列表改点 **「人物总表 characters.md」** → ④ **滚到文件最底部**追加新人物（不要改上方旧段落）→ ⑤ **「保存」** → ⑥ 确认 | 人物初始设定只增不改。对应 **第 ② 层**。 |
| **A3** Codex 条目 | ① 顶栏 **「写作」** → ② 左侧点 **「设定库」** → ③ 搜索框右侧蓝色 **「+」** → ④ 弹窗输入名称（如「女主·林晚」）→ ⑤ 列表点刚建的条目 → ⑥ 主区编辑内容（约 2 秒自动保存）→ ⑦ 写作/写书对话前，在列表条目左侧 **勾选框** 打上 ✓ | 按场景注入人物/地点，省 token，且不易误改 `characters.md`。 |
| **A4** 伏笔清单（可选） | ① **「写作」** → ② **「全局文件」** → ③ 点 **「伏笔线索 plot_threads.md」** → ④ 编辑 → ⑤ **「保存」** → ⑥ 确认 | 给后面的「续章灵感」「连续性检查」提供清单。 |

---

#### 阶段 B：规划这一章写什么

| 步骤 | 面板操作（从上到下点） | 为了什么 |
|------|------------------------|----------|
| **B1** 建章 | ① 顶栏点 **「规划」** → ② 主区中央点蓝色大按钮 **「+ 创建第一章」**（若已有章节，则点上方的章节下拉框选章）→ ③ 确认框 **确定** | 建立章节编号与 `plan.json`；后面正文、概述都对齐这个章号。 |
| **B2** 加场景 | ① 仍在 **「规划」** → ② 主区点虚线卡片 **「+ 添加场景」**，或点工具栏 **「+ 场景」** → ③ 弹窗输入场景名（不能为空）→ **确定** | 一章拆多个场景，便于分段续写。 |
| **B3** 写 Beat | ① **「规划」** → ② 主区 **点击某个场景卡片**（卡片高亮）→ ③ 下方出现 Beat 面板 → ④ 在 **Scene Beat** 文本框写提纲 → ⑤ 点 **「保存 Beat」** | Beat 会注入写书对话（默认 beats 模式），AI 才知道这一场写什么。也可点 **「用此 Beat 去写书对话 →」** 直接跳转。 |
| **B4** 勾选 Codex | ① 顶栏切 **「写作」** 或 **「写书对话」** → ② 左侧 **「设定库」** → ③ 给本章相关条目 **勾选** ✓ | 写书对话只带勾选条目进上下文，减少无关人物干扰。 |
| （可选）改章名 | **「规划」** → 工具栏 **「重命名」** → 输入标题 → 确认框 **确定** | 章节下拉框和侧栏会显示你起的标题。 |

---

#### 阶段 C：出正文

| 步骤 | 面板操作（从上到下点） | 为了什么 |
|------|------------------------|----------|
| **C1** 自己写开头 | ① 顶栏 **「写作」** → ② 主区右上 **章节下拉框** 选「第 N 章」→ ③ 中间编辑器输入或粘贴正文（停笔约 **2 秒自动保存**；也可点 **「保存」**） | 给 AI 文风锚点；没章节时主区只显示「+ 创建第一章」，需先做完 B1 或点它建章。 |
| **C2** AI 续写 | ① 顶栏 **「写书对话」** → ② 看主区顶部灰字 **「当前场景已选中 · 第 N 章」**（若显示「建议先在 Plan 选中场景」，回 **规划** 点一下场景卡片）→ ③ 底部大输入框写指令，如 `续写 800 字` → ④ 点蓝色 **「发送」** → ⑤ 看上方气泡流式出字 | AI 读取三层设定 + Beat + 勾选 Codex + 章节正文。右侧可选模型下拉框。 |
| **C3** 对照与定稿 | ① 侧栏 **「写书记录」** → 点 **「第 N 轮」** → ② 主区出现 **左右对照**（你的指令｜AI 回复）→ ③ 若显示 **「✓ 本轮 AI 正文已写入章节」** 表示已自动追加 | 可逐轮比较哪段更好；侧栏与气泡里带 **✓已写入** 标记。 |
| **C4** 确认章节正确 | ① **写书对话** 顶栏 **「查看本章正文」**（或 **写作** → 选章）→ ② 通读 `ch00x.md` → ③ 不满意：**「撤销写入」** 或直接在写作里改字（自动保存） | **以写作模式里的章节文件为准**；对话只是过程记录。 |
| **C5** 误写入撤销 | **「写书对话」** → **「撤销写入」** → 确认 | 只回滚**上一次**自动追加；更早版本见 `data/backups/`。 |

> **定稿口诀**：对照满意 → 写作里核对全文 → 生成概述（D1）。多轮续写会**按顺序追加**到同一章，不是只保留最后一轮。

#### 阶段 D：章后维护（每章写完做）

| 步骤 | 面板操作（从上到下点） | 为了什么 |
|------|------------------------|----------|
| **D1** 生成概述 | ① **「写书对话」** → ② 点 **「生成概述」** → ③ 确认框 **确定** → ④ 弹窗里看 AI 生成的摘要 | 追加到 `summaries.md`（**第 ③ 层**）。写书对话底部按钮，**不在「统计」里**。 |
| **D2** 更新人物现状 | **方式一**：**「写作」** → **「全局文件」** → **「当前状态 char_current.md」** → 编辑 → **「保存」** → 确认。**方式二**：**「设定库」** → 点人物条目直接改（自动保存） | 记录「现在」的外貌/关系/持有物，不动 `characters.md` 初始设定。 |
| **D3** 更新伏笔 | **「写作」** → **「全局文件」** → **「伏笔线索 plot_threads.md」** → 编辑 → **「保存」** → 确认 | 给续章灵感和检查提供依据。 |
| **D4** 连续性检查 | ① **「写书对话」** → ② 点 **「连续性检查」** → ③ 弹窗看问题清单 | 每 3～5 章做一次；用 DeepSeek，省额度。 |
| **D5** 续章灵感 | ① **「写书对话」** → ② 点 **「续章灵感」** → ③ 弹窗输入章数（1–10）→ ④ 看建议（**不写进文件**） | 卡文时用；需已有概述或伏笔效果更好。 |

#### 阶段 E：日常循环（对照面板）

| 想做的事 | 面板路径 |
|----------|----------|
| 规划下一场景 | **规划** → 点场景 / **+ 添加场景** → 写 Beat → **保存 Beat** |
| AI 写这一段 | **写书对话** → 确认顶部场景提示 → **发送** |
| 自己改字 | **写作** → 章节下拉框选章 → 编辑器改 |
| 本章收尾 | **写书对话** → **生成概述** |
| 查矛盾 | **写书对话** → **连续性检查** |
| 看写了多少字 / 花了多少钱 | **统计** → 主区看卡片 |
| 闲聊脑暴（不写正文） | **自由聊** → 底部输入 → **发送** |

顶栏五个模式对照：

| 顶栏按钮 | 什么时候点 |
|----------|------------|
| **规划** | 开新章、加场景、写/改 Beat |
| **写作** | 自己改正文、编辑全局设定、改 Codex |
| **写书对话** | 续写、生成概述、检查、续章灵感 |
| **自由聊** | 与写作无关的聊天 |
| **统计** | 只看字数和 API 费用 |

#### 常见错误顺序（避免）

| 错误 | 后果 |
|------|------|
| 没写 `world.md` 就大量续写 | AI 随意发明规则，后文难以统一 |
| 没 Beat 就续写 | 生成散、跑题，浪费 token |
| 没生成概述就写很多章 | 模型对前文记忆变弱，容易吃书 |
| 在 `characters.md` **中间删改**旧段落 | 破坏「只增不改」策略，缓存失效，旧设定可能被 AI 遗忘 |
| 多标签同时写 | Web 单进程共享会话，会互相覆盖 |

### 1.6 数据修改与删改原则

本项目的核心设定文件**默认只追加、不轻易删改**——不是为了禁止你改，而是为了 **Prompt Cache 命中** 和 **长篇一致性**。

| 数据 | 默认策略 | 可以改吗？ | 删改时怎么办 |
|------|----------|------------|--------------|
| `world.md` | 极少改动 | 可以，但影响全局 | 点「保存」会**二次确认**；自动备份在 `data/backups/` |
| `characters.md` | **只追加** | 可以改旧内容，但不推荐 | 保存前确认；更推荐末尾追加或 Codex 新条目 |
| `summaries.md` | **只追加**（概述按钮写入） | 可手工修概述 | 保存前确认；优先用「生成概述」自动追加 |
| `char_current.md` | 随章更新 | 经常改 | 保存前确认 |
| `plot_threads.md` | 手动维护 | 经常改 | 保存前确认 |
| Codex 条目 | 按条目独立文件 | 随意编辑 | 自动保存；删改影响小，备份同样生效 |
| 章节正文 `ch00x.md` | 正常写作 | 随意改 | 自动保存 + 备份；「撤销写入」有确认框 |
| 写书 / 自由聊记录 | 可清空 | 可删 | 「清空」**二次确认**；章节文件不受影响 |
| Plan 场景 / 章节标题 | 可改 | 可改 | 重命名有确认；场景删除 API 保留（需确认后调用） |

**界面上的二次确认（不能省，但也不能没有）：**

| 操作 | 在面板上怎么触发 | 确认方式 |
|------|------------------|----------|
| 新建章节 | **规划** 或 **写作** 主区 **「+ 创建第一章」** | 浏览器确认框 |
| 重命名章节 | **规划** → 工具栏 **「重命名」** | 输入标题后再确认 |
| 保存全局设定 | **写作** → **全局文件** → 编辑后右上 **「保存」** | 确认框 + 风险说明 |
| 生成概述 | **写书对话** → **「生成概述」** | 确认框 |
| 清空写书对话 | **写书对话** → 右上 **「清空」** | 确认框 |
| 清空自由聊 | **自由聊** → 右上 **「清空」** | 确认框 |
| 撤销写入章节 | **写书对话** → **「撤销写入」** | 确认框 |
| 切换主力模型 | **写书对话** 底部模型下拉框（有对话历史时） | 确认框 |
| 切换全局文件未保存 | **写作** → 换另一个全局文件或章节 | 「是否保存」确认框 |

> 全局设定文件**不会自动保存**，须点「保存」并确认——避免误删段落被静默写入。章节正文与 Codex 条目仍自动保存。

### 1.4 命令行 vs Web 面板对照

| 原 CLI 操作 | Web 面板操作（完整路径） | 说明 |
|-------------|--------------------------|------|
| 编辑 `world.md` | **写作** → 侧栏 **全局文件** → **世界观 world.md** → 编辑 → **保存** → 确认 | 不自动保存 |
| 编辑 `characters.md` | **写作** → **全局文件** → **人物总表 characters.md** → 末尾追加 → **保存** | 只增不改 |
| 手动创建 `ch001.md` | **规划** → **「+ 创建第一章」** → 确认 | 自动编号 |
| `/summary` | **写书对话** → **「生成概述」** → 确认 | 追加 summaries.md |
| `/check` | **写书对话** → **「连续性检查」** | 弹窗看结果 |
| `/outline` | **写书对话** → **「续章灵感」** → 输入章数 | 不写文件 |
| `/undo` | **写书对话** → **「撤销写入」** → 确认 | 回滚上次自动写入 |
| `/patch 内容` | **写作** → **全局文件** → characters 末尾追加；或 **设定库** → **「+」** | 无专用 patch 按钮 |
| `/new` | **写书对话** → 右上 **「清空」** → 确认 | 只清对话，不动设定文件 |

> 「统计」模式仅展示字数与费用，**不包含**生成概述/检查按钮（这两个在写书对话输入框下方）。

## 3. 六大模式详解

### 3.0 概览模式（书架）📖 像看小说一样总览

顶栏点 **「概览」**（无左侧边栏），一屏看清当前这本书：

| 区块 | 内容 |
|------|------|
| 顶部 | **书名**、**世界标签**（如 世界一）、当前写到**第几章** |
| 世界观 | `world.md` 摘要（快穿框架等全书设定） |
| 当前世界 | 已勾选 Codex 条目摘要（如 世界一_娱乐圈） |
| 大纲 | 每章标题 + 场景列表 + Beat 摘要 |
| 章节目录 | **点某一章** → 下方以正文排版**阅读**该章（只读） |
| 章节概述 | `summaries.md` 摘要 |

**改书名**：概览页 **「改书名」** → 填书名、世界标签、一句话简介 → 写入 `data/project.json`，顶栏书名同步更新。

#### 同时写多本书？

当前是 **单书模式**：一个 `data/` = 一本书。顶栏副标题会提示。

| 做法 | 说明 |
|------|------|
| **推荐** | 复制整个 `novel_writer` 文件夹为 `novel_writer_书B`，各开各的 Web 端口 |
| 进阶 | 同一仓库用 **Git 分支** 隔离不同书的 `data/` |
| 暂不支持 | 在一个 Web 里下拉切换多本书（未实现） |

---

### 3.1 Plan 模式（规划）

用于规划章节结构，在写正文之前先搭框架。

| 操作 | 面板位置 |
|------|----------|
| 新建章节 | 顶栏 **「规划」** → 主区 **「+ 创建第一章」**（或 **写作** 主区同款按钮）→ 确认 |
| 重命名章节 | **规划** → 工具栏 **「重命名」** → 输入 → 确认 |
| 添加场景 | **规划** → 主区 **「+ 添加场景」** 卡片，或工具栏 **「+ 场景」** → 输入标题（**不能为空**） |
| 编辑 Scene Beat | **规划** → 点击场景卡片 → 下方 Beat 面板 → **「保存 Beat」** |
| 标记完成 | 场景卡片标题旁 **复选框** ✓ |
| 调整顺序 | **规划** → 拖拽场景卡片上下 |
| 去写书对话 | Beat 面板 **「用此 Beat 去写书对话 →」** |

> 💡 **Scene Beat** 是场景的写作提纲。填写后，Chat 模式会自动将 Beat 注入给 AI，引导生成方向。

### 3.2 Write 模式（写作）

顶栏点 **「写作」** 进入。主区是章节编辑器；左侧三个标签：

| 侧栏标签 | 点开什么 | 主区显示 |
|----------|----------|----------|
| **设定库** | 条目名 / 右侧 **「+」** 新建 | Codex 条目编辑器（自动保存） |
| **写书记录** | 某条「你 #N / AI #N」 | 仅跳转预览；点一下会切到 **写书对话** 模式 |
| **全局文件** | world.md、characters.md 等 | 全局设定编辑器（须手动 **「保存」**） |

正文相关：

- **切换章节**：主区右上 **章节下拉框**（无章节时主区显示 **「+ 创建第一章」**）
- **编辑正文**：中间大文本框
- **保存章节 / Codex**：点 **「保存」**，或停笔约 **2 秒**自动保存
- **保存全局设定**：右上 **「保存」** → 确认框（不自动保存）
- **字数**：底栏右侧 pill（如 `1,234 字`）

> 💡 切换章节前会自动保存章节正文；全局设定见 [§1.6](#16-数据修改与删改原则)。

#### 追加人物设定（等同 `/patch`）

Web 没有单独的「追加 patch」按钮。推荐两种方式：

1. **设定库 Codex（推荐）**：侧边栏新建人物/地点条目，勾选后注入写书对话，天然避免误改旧内容。
2. **全局文件 → 人物总表**：滚到**文件末尾**手动追加新段落，**不要修改上方已有设定**（与 CLI `/patch` 只增不改一致）。

### 3.3 Chat 模式（写书对话）⭐ SSE 流式输出

与 AI 协作写作的核心模式。本版本已实现 **SSE 流式输出**，AI 回复逐字实时显示在气泡中。

#### 面板布局

顶栏点 **「写书对话」**。主区上方是历史气泡；底部从左到右：

| 区域 | 控件 |
|------|------|
| 顶条 | 灰字场景提示 `chatSceneHint`、右上 **「清空」** |
| 输入区 | 多行输入框（写作指令） |
| 输入区下方 | **「发送」** · **「生成概述」** · **「连续性检查」** · **「续章灵感」** · **「撤销写入」** |
| 输入区右上方 | 模型下拉框（Claude / DeepSeek） |

#### 发送指令

1. 底部输入框输入，例如 `续写500字，保持紧张感`
2. 点蓝色 **「发送」**
3. 上方气泡流式出字；底栏费用与 cache 状态会更新

#### 指令类型识别

| 指令类型 | AI 输出格式 | 用途 |
|----------|------------|------|
| 续写 / 扩写 / 润色 / 修改 | 纯正文 | 可直接复制到编辑器 |
| 提问 / 讨论 | `[讨论]` / `[问答]` / `[建议]` 开头 | 对话性回复，不算正文 |

#### 辅助按钮（等同 CLI 命令）

**写书对话** 底部输入框下方一行按钮（概述/检查/灵感走 DeepSeek，省额度）：

| 面板按钮 | 等同 CLI | 作用 |
|----------|----------|------|
| **生成概述** | `/summary` | 为最新章节生成概述，追加到 summaries.md（有确认框） |
| **连续性检查** | `/check` | 对照设定列出最新章矛盾点 |
| **续章灵感** | `/outline` | 弹窗输入章数，给后续剧情建议（不写文件） |
| **撤销写入** | `/undo` | 回滚上一次 AI 自动写入章节的正文（有确认框） |

#### 注意事项

- 发送中按钮变为「生成中…」并禁用，**流传输全程保持锁定**，防止并发乱序
- 如果已有请求进行中，再次点击会弹出「请等待当前请求完成」
- **首字节超时 90 秒**；收到数据后改为 **180 秒无新内容**才超时（适合长文续写）
- 连接异常或后端报错会 toast 提示，并显示在错误栏
- 流式完成后 `done` 事件携带本次费用，底栏立即更新
- 清空对话记录前会弹出**确认框**，防止误清

#### 场景联动

在 Plan 模式中选中某个场景后，Chat 会自动携带该场景的 Beat 作为上下文注入 AI。

### 3.4 Free 模式（自由聊天）

顶栏点 **「自由聊」**。左侧 **「聊天记录」** 可回顾；主区布局与写书对话类似，但**无** Scene Beat / 设定注入。

| 控件 | 位置 |
|------|------|
| 输入 | 底部多行框 |
| **发送** | 输入框下方蓝色按钮 |
| 模型 | 输入区右上方下拉框（默认 DeepSeek） |
| **清空** | 主区右上 **「清空」** → 确认 |

不写章节、不用三层缓存；历史存 `free_chat.json`，与写书对话分开。

| 内容 | 说明 |

## 8. 备份与数据安全

数据「只增不改」与删改二次确认的完整说明见 **[§1.6](#16-数据修改与删改原则)**。

### 自动备份机制

每次写入文件前自动备份到 `data/backups/` 目录：

- 备份文件名格式：`{原文件名}_{YYYYMMDD_HHMMSS}{扩展名}`
- **每个文件最多保留 10 份**备份，超出自动删除最旧的
- 覆盖范围：章节文件、plan.json、所有全局 .md 文件、Codex 条目

### 手动恢复

1. 进入 `data/backups/` 目录
2. 找到对应文件名和时间戳的备份
3. 复制到原路径覆盖即可

### 重要提示

- `data/` 目录包含所有创作数据，**定期手动备份整个 data 目录到外部存储**
- 程序退出时会自动保存对话记录到 `data/session_autosave.json`

## 9. 常见问题 FAQ

**Q：顶部一直显示红色横幅「API Key 未配置」？**
A：检查 `.env` 文件是否存在于项目根目录，Key 是否填写正确（不含多余空格或引号）。

**Q：发送后长时间没有响应？**
A：写书流式：90 秒内无任何数据会提示连接超时；开始输出后若 180 秒无新内容会提示生成超时。概述/检查等普通请求仍为 120 秒总超时。

**Q：流式输出中途停止？**
A：多为网络抖动、API Key 失效或服务端报错。已生成部分会保留在对话记录中，可刷新后查看并补充指令。

**Q：切换章节后编辑器内容丢失？**
A：切换章节前会自动保存；停止输入约 2 秒也会自动保存。若仍丢失，检查 `data/backups/` 恢复备份。

**Q：Codex 勾选了但 AI 好像没用到？**
A：确认上下文模式为 `beats` 或 `codex`，且勾选的条目内容不为空。

**Q：费用统计不准确？**
A：费用为**预估值**，基于 token 数与 `prices.json`（或内置）单价计算；详细记录见 `cost_log.jsonl`。实际账单以提供商后台为准。

**Q：AI 误把讨论写进章节了？**
A：Chat 模式点「撤销写入」（等同 CLI `/undo`），或从 `data/backups/` 恢复章节备份。

**Q：想重置对话历史重新开始？**
A：Chat 模式底部「清空记录」按钮（会弹出确认框）。注意清空后无法恢复。

**Q：全局设定改了半天怎么没生效？**
A：全局文件不会自动保存。编辑后须点「保存」并通过确认框；切换其他文件时也会提示是否保存未提交的修改。

**Q：报错 `Your request was blocked`？**
A：写书对话 **DeepSeek 正常、kie/Claude 不行** 时，多半是 kie 网关拦截了 Anthropic SDK 默认请求头（v0.5.2 已修）。请 **重启 `python web_app.py`** 后再试 kie。

若仍失败：

1. 检查 `.env` 里 `KIE_API_KEY` 是否正确、账户有余额  
2. 用 **`http://127.0.0.1:8765`** 打开 Web  
3. 临时可继续用 **DeepSeek** 写书（无 Prompt Cache，但可用）

保存 Codex/全局设定只访问本机，一般不会出现此英文报错。

**Q：如何只让 AI 知道本章相关人物，减少 token？**
A：在 Codex 中为本章人物创建条目并勾选，AI 会只使用勾选的条目而非整个 characters.md。
