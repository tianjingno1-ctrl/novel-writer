# 一、快速上手

## 1.1 环境准备

```bash
cd novel_writer
copy .env.example .env    # 填入 KIE_API_KEY、DEEPSEEK_API_KEY
pip install -r requirements.txt
python web_app.py         # 或双击 启动web.bat
```

浏览器访问 `http://127.0.0.1:8765`。顶栏红色 API Key 横幅消失 = 配置成功。

## 1.2 界面认路

```
顶栏：[概览] [规划] [写作] [写书对话] [自由聊] [统计]  ……右侧 ⚙️
左侧：标签页 + 搜索框 + 蓝色 [+]
主区：编辑器 / 场景看板 / 对话气泡
底栏：概述数 · 设定数 · 费用 · 字数 · cache
```

## 1.3 极简写作路径

```
设定(world/style/人物) → 规划(章+Beat) → 手写开篇 → 写书对话续写 → 生成概述 → 章后维护
```

完整分步见 **[三、写作流程](#三写作流程)**。数据文件怎么维护见 **[二、系统设定](#二系统设定)**。

# 二、系统设定

本章说明：**有哪些文件、谁更新、怎么保存、写之前要不要填、AI 会不会读**。  
程序**不会硬拦**你跳过必填项，但跳过会导致文风跑偏、吃书、浪费 token。

## 2.1 一本书 = 一个 `data/` 目录

| 概念 | 说明 |
|------|------|
| 单书模式 | 一个 `data/` = 一本书；`data/project.json` 存书名、世界标签 |
| 多书 | **推荐**复制整个 `novel_writer` 文件夹；或 Git 分支隔离 `data/` |
| 新开一本 | 见 [§6.4 新开一本](#64-新开一本丢弃全部旧数据) |

```
data/
├── world.md, style.md, characters.md     # 地基设定
├── char_static.md, char_dynamic.md       # 人物冷热分层
├── summaries_recent.md, summaries_archive.md
├── plot_threads_locked.md, plot_threads_active.md
├── plan.json, project.json               # 规划与书名
├── chapters/ch001.md …                   # 章节正文
├── codex/entries/*.md, codex/active.json # 设定库
├── backups/                              # 自动备份
├── history/                              # 档案变更留痕
└── session_autosave.json                 # 写书对话自动保存
```

## 2.2 数据文件总表（核心）

> **保存方式**：「手动+确认」= 写作 → 全局文件 → 编辑 → **保存** → 确认框；「自动」= 停笔约 2 秒或点保存，无确认框。

| 文件 | 用途 | 更新机制 | 保存方式 | 缓存层 | 写作前必填 | 谁写入 / 何时改 |
|------|------|----------|----------|--------|------------|-----------------|
| `world.md` | 世界观、五点骨架、章节节拍、爽点表 | 极少改动 | 手动+确认 | ① | **强烈建议**（规划/续写前） | 开书时手写；换世界时改 |
| `style.md` | 文风锚点、示范句、禁用词 | 开书定稿后少改 | 手动+确认 | ① | **写第一章正文前必须** | 开书时手写 |
| `characters.md` | 人物初始总表 | **只追加** | 手动+确认 | ② | 建议 | 开书追加；新人物**滚到末尾**追加 |
| `char_static.md` | 性格锚点、禁止写法、深层软肋 | 极少改动 | 手动+确认 | ② | 建议 | 开书填写；本质人设变化时改 |
| `char_dynamic.md` | 当前情绪、关系、表层软肋 | **每章更新** | 手动+确认 | ④ 动态 | 章后维护 | 每章定稿后手写；**角色观察**可写入 |
| `summaries_recent.md` | 最近 3–5 章概述 | **只追加** | 按钮追加 | ④ 动态 | 章后维护 | **生成概述**按钮；旧条剪切到 archive |
| `summaries_archive.md` | 旧章概述归档 | **只增不改** | 手动剪切 | ③ | — | 从 recent 剪切迁入 |
| `plot_threads_locked.md` | 已钉死细节（数字、专名） | **只增不改** | 手动 / 按钮 | ③ | 出现新专名时 | 手写追加；**提取细节**可自动追加 |
| `plot_threads_active.md` | 未回收 / 已回收伏笔 | 每章维护 | 手动+确认 | ④ 动态 | 可选 | 每章定稿后更新 |
| `plan.json` | 章节标题、场景、Beat、节奏档位 | 随规划改 | 规划面板自动 | — | **续写前要有 Beat**（beats 模式） | 规划模式编辑 |
| `chapters/ch00x.md` | 章节正文 | 正常写作 | **自动**+备份 | — | 有章才能写 | 写作模式 / AI 追加或替换 |
| Codex 条目 | 按世界/人物细则 | 随意编辑 | **自动**+备份 | 勾选注入 | **写书前建议勾选** | 设定库新建；勾选控制是否注入 |
| `session_autosave.json` | 写书对话历史 | 可清空 | 自动 | — | — | 写书对话；**清空**只清对话 |
| `free_chat.json` | 自由聊历史 | 可清空 | 自动 | — | — | 与写书对话独立 |

**已废弃占位**（界面标灰，续写不读）：`char_current.md`、`summaries.md`、`plot_threads.md` → 请改用上表拆分文件。

### 写作前必填 vs 章后维护（一览）

| 阶段 | 必填 / 强烈建议 | 可选 |
|------|-----------------|------|
| **开书地基** | `world.md` 节拍表、`style.md` 文风、`characters.md` / `char_static.md` | `plot_threads_*`、Codex |
| **动笔前** | 建好章 + 场景 + **Beat**；勾选 Codex | 改章名 |
| **第一章正文前** | **`style.md` 必须定稿** | — |
| **每章定稿后** | 生成概述 → `summaries_recent`；更新 `char_dynamic` | 剪切旧概述到 archive |
| **每 3–5 章** | 连续性检查 | 重复检查、爽点检查 |

> **程序行为**：不填 `style.md` 也能点「发送」，但 AI 缺少文风约束；没 Beat 在 `beats` 模式下续写容易跑题。见 [§6.2 常见错误](#62-常见错误顺序)。

## 2.3 Prompt Cache 分层（仅 kie/Claude 写书对话）

续写时 system prompt 按层组装，**改缓存层文件会刷新缓存、增加费用**：

| 层 | 内容 | 对应文件 |
|----|------|----------|
| ① | 世界观 + 文风 | `world.md` + `style.md` |
| ② | 人物锚点 + 总表 | `char_static.md` + `characters.md`（或勾选 Codex 替代） |
| ③ | 稳定档案 | `summaries_archive.md` + `plot_threads_locked.md` |
| ④ 动态 | 每章变化 | `char_dynamic.md` + `summaries_recent.md` + `plot_threads_active.md` + 当前场景 Beat |

底栏 **cache pill** 为只读指示器：显示上次写书请求的缓存命中/写入 token。DeepSeek 无 Prompt Cache；概述/检查/质量按钮**不更新**该 pill。

## 2.4 上下文策略（⚙️ 设置）

| 模式 | 注入内容 | 适用 |
|------|----------|------|
| `beats` | 当前场景 Beat + Codex | **默认推荐** |
| `summaries` | 章节概述历史 | 长篇连贯优先 |
| `turns` | 最近 N 轮对话 | 轻量省 token |
| `codex` | 仅用勾选 Codex 替代人物设定 | Codex 维护精细时 |

## 2.5 AI 提供商

| 提供商 | 标识 | 模型 | 用途 |
|--------|------|------|------|
| kie.ai Claude | `kie` | claude-sonnet-4-6 | 写书对话主力；支持 Prompt Cache |
| DeepSeek V4 Pro | `deepseek` | `deepseek-v4-pro` | 写书对话 / 概述 / 检查 / 自由聊 |

- **主力提供商**：写书对话「发送」使用  
- **辅助提供商**：生成概述、连续性检查、六项质量按钮  
- 费用为**预估**，详见 `cost_log.jsonl` 与 `prices.json`

## 2.6 设置抽屉（⚙️）其他项

| 设置项 | 说明 |
|--------|------|
| 写书对话保留轮数 | 默认 10 轮（`turns` 相关） |
| **档案留痕** | 追踪 world / char / 概述 / 伏笔 / plan 变更；可**撤销**单次修改 |
| **刷新第 0 章基准快照** | 用当前追踪文件覆盖 `data/history/baseline/`（开书定稿后点一次；慎用） |

> 章节正文不在档案留痕范围内；更早版本见 `data/backups/`。

# 三、写作流程

按顺序做，**不要跳步**。面板名称与顶栏一致。

## 3.1 先认侧栏（随模式变化）

| 模式 | 顶栏 | 左侧边栏 |
|------|------|----------|
| 概览 | **概览** | 无 |
| 规划 | **规划** | **场景** |
| 写作 | **写作** | **目录** · **设定库** · **写书记录** · **全局文件** |
| 写书对话 | **写书对话** | **目录** · **写书记录** · **设定库** |
| 自由聊 | **自由聊** | **聊天记录** |
| 统计 | **统计** | 无 |

## 3.2 阶段 A：搭地基（开新书做一次）

> 不必先建章节。此阶段只动设定。

| 步骤 | 操作 | 目的 |
|------|------|------|
| A1 | **写作** → **全局文件** → **world.md** → 填主线、五点骨架、章节节拍表 → **保存** | 结构地基；缓存① |
| A2 | 同上 → **style.md** → 填文风 → **保存** | **写第一章前必须**；缓存① |
| A3 | 同上 → **characters.md** 末尾追加人物 → **保存** | 人物初始设定；只增不改 |
| A3+ | 同上 → **char_static.md** 填性格锚点、禁止写法 → **保存** | 防人设漂移；缓存② |
| A4 | **写作** → **设定库** → **+** → 建世界条目 → 写书前 **勾选** ✓ | 按场景注入细则 |
| A5 | **全局文件** → **plot_threads_active.md** / **plot_threads_locked.md**（可选） | 伏笔与钉子清单 |

## 3.3 阶段 B：规划本章

| 步骤 | 操作 | 目的 |
|------|------|------|
| B1 | **规划** → **+ 创建第一章** → 确认 | 建立 `plan.json` 与章号 |
| B2 | **+ 添加场景** → 输入场景名（不能为空） | 分段续写 |
| B3 | 点场景卡片 → 填 Beat（五段格式）→ **保存 Beat** | 注入写书对话 |
| B4 | **设定库** 勾选本章相关 Codex | 减少无关 token |

**Beat 标准格式**：

```
【场景目的】……
【人物动作】……
【关键台词】……（可选）
【情绪目标】爽/甜/揪心/燃/好奇
【节奏档位】快 / 中 / 慢
【结尾钩子】……
```

## 3.4 阶段 C：出正文

| 步骤 | 操作 | 目的 |
|------|------|------|
| C1 | **写作** → 选章 → 手写 200–500 字开篇 | 给 AI 语气样本 |
| C2 | **写书对话** → 指令库选模板 → **发送** | AI 续写（SSE 流式） |
| C3 | **写书记录** → 点轮次 → 对照 → **替换本章**（定稿用替换，非追加） | 避免旧稿+新稿叠在一起 |
| C4 | **查看本章正文** 或回 **写作** 通读 | 以章节文件为准 |
| C5 | **撤销写入** 或 `data/backups/` | 误写入回滚 |

**定稿口诀**：对照 → **替换本章** → 写作核对 → 生成概述（D1）。

### 写作目标、标题、保存与定稿（易错点）

| 概念 | 在哪里 | 说明 |
|------|--------|------|
| **写作目标** | 写书对话顶栏 **「目标」** 下拉 + 输入框上方绿条「将写入第 N 章」 | AI **发送后写入的章**；与写作模式正在看的章可能不同 |
| **章节标题** | AI 首行 `【章节标题】…` → 保存为 `# 第N章 · 标题` + `plan.json` | **重命名** 会同步改 md 首行；续写带「续写」为追加模式 |
| **保存章节** | 写作模式 **保存** / 自动保存 | 只写 `chXXX.md`，**默认不询问定稿** |
| **本章定稿** | 写书对话底部 / 写作页 **本章定稿** | 概述+观察+钉子+质检，约 2–3 次 API；章阶段性完成再做 |
| **保存后询问定稿** | 设置 → 勾选「手动保存章节后询问本章定稿」 | 默认关；小改不必开 |

**口诀**：先改 **目标** 再发送；发完看 toast 第几章；小改只 **保存**，章写完再 **定稿**。

**写错章救援**：**撤销写入** → 改 **目标** → 写书记录 **对照** → **用此轮 AI 回复替换本章**；或手工剪切 + `data/backups/`。

## 3.5 阶段 D：章后维护（每章）

| 步骤 | 操作 | 写入哪里 |
|------|------|----------|
| D1 | **生成概述** → 确认 | `summaries_recent.md`（**不**自动改人物/伏笔） |
| D2 | **全局文件** → **char_dynamic.md** → **保存** | 当前人物状态 |
| D3 | **plot_threads_locked** 追加钉子；**plot_threads_active** 更新伏笔 | 防吃书 |
| D4 | **连续性检查** | 弹窗看问题（每 3–5 章） |
| D5 | **续章灵感** → **写入下一章 Beat** | 自动建下一章 + plan + `outline_latest.md` |

旧概述条数多时：将 `summaries_recent` 旧条**剪切**到 `summaries_archive`。

## 3.6 阶段 E：日常循环

| 想做 | 路径 |
|------|------|
| 规划场景 | **规划** → 场景 / **+ 添加场景** → Beat |
| AI 写段 | **写书对话** → 确认场景提示 → **发送** |
| 自己改字 | **写作** → 章节下拉 → 编辑 |
| 本章收尾 | **生成概述** |
| 查矛盾 | **连续性检查** |
| 看字数费用 | **统计** |
| 闲聊脑暴 | **自由聊** |

# 四、界面与操作

## 4.1 概览（书架）

顶栏 **概览**：书名、世界标签、大纲、点章**只读**阅读正文。  
**改书名** → 写入 `project.json`。

## 4.2 规划

| 操作 | 位置 |
|------|------|
| 新建 / 重命名章 | **+ 创建第一章** / 工具栏 **重命名** |
| 场景 Beat | 点场景卡片 → Beat 面板 → **保存 Beat** |
| 节奏档位 | Beat 内 `【节奏档位】` 或场景 `pace` 下拉 |
| 去写书 | Beat 面板 **用此 Beat 去写书对话 →** |

## 4.3 写作

| 侧栏 | 说明 |
|------|------|
| **目录** | 世界 → 章 → 场景折叠 |
| **设定库** | Codex；**自动保存**；勾选=注入 AI |
| **全局文件** | 见 [§2.2 总表](#22-数据文件总表核心)；**手动保存+确认** |
| **写书记录** | 跳转写书对话对照 |

章节正文：**自动保存**。全局设定：**不自动保存**。

## 4.4 写书对话

| 控件 | 说明 |
|------|------|
| **发送** | 续写/润色；SSE 流式；首字节 90s、空闲 180s 超时 |
| **生成概述** | 追加 `summaries_recent` |
| **连续性检查** | 对照设定列矛盾 |
| **人物检查** | 对照 `char_static` + `char_dynamic` |
| **角色观察** | AI 提案 → 确认后写入 `char_static` / `char_dynamic` |
| **提取细节** | 从正文提取钉子 → 可追加 `plot_threads_locked` |
| **重复检查** | 当前章 / 近 3 章 / 全书 |
| **爽点检查** | 对照 `world.md` 节拍与概述 |
| **续章灵感** | 建议剧情；可写入下一章 Plan |
| **撤销写入** | 回滚上次 AI **追加**到章节的正文 |
| **清空** | 只清对话；章节文件保留 |

**指令类型**：续写/润色 → 纯正文；`[讨论]`/`[问答]` 开头 → 不写进章节。

**写书记录对照**：点 **第 N 轮** → 双栏比较 → **用此轮 AI 回复替换本章** 定稿。

规划里选中场景后，写书对话自动携带该场景 Beat。

## 4.5 自由聊

无 system prompt、无设定注入、不写章节；历史在 `free_chat.json`。

| 操作 | 位置 |
|------|------|
| 新建话题 | 侧栏 **+** 或顶栏 **新建**（如「世界观」「人物」「第一世界」各开一个） |
| 切换话题 | 侧栏 **讨论话题** 列表，点选即切换 |
| 重命名 / 删除 | 顶栏 **重命名** / **删除** |
| 清空 | **清空本话题**（只清当前话题，其他话题保留） |

每个话题独立保留对话；首条消息可自动用作话题名。旧版单条 `messages` 会在启动时迁入「默认话题」。

## 4.6 统计

总字数、分章字数、API 费用预估。**不含**生成概述/检查按钮（在写书对话）。

# 五、质量工具

## 5.1 六项问题对照

| 问题 | 维护文件 | 工具按钮 |

## 5.3 节奏档位参考

| 档位 | 段落 | 句式 | 场景 |
|------|------|------|------|
| 快 | 1–2 行/段 | 短句、动词密 | 冲突、打脸 |
| 中 | 3–4 行/段 | 正常叙述 | 日常、对话 |
| 慢 | 5 行+/段 | 感官细节 | 感情、余韵 |

一章建议至少两种档位交替。


指令库用 **续写（情感具象）**，或手动加「不要直接写情绪名，用动作、细节、环境传递」。

# 六、注意事项

## 6.1 删改原则与二次确认

核心设定**默认只追加、不轻易删改**——为 Prompt Cache 命中与长篇一致性。

| 数据 | 策略 | 保存确认 |
|------|------|----------|
| `world.md` / `style.md` | 少改 | 手动保存 + 确认框 |
| `characters.md` | 只追加 | 同上 |
| `char_static` / `*_archive` / `plot_threads_locked` | 只增不改 | 同上 |
| `char_dynamic` / `summaries_recent` / `plot_threads_active` | 经常改 | 同上 |
| 章节 / Codex | 随意改 | 自动保存 + 备份 |
| 写书 / 自由聊 | 可清空 | 清空确认框 |

**必出确认框的操作**：新建章、重命名章、保存全局设定、生成概述、清空对话、撤销写入、切换主力模型（有历史时）、切换未保存的全局文件。

## 6.2 常见错误顺序

| 错误 | 后果 |
|------|------|
| 没写 `world.md` 节拍就续写 | 节奏散、爽点错位 |
| 没写 `style.md` 就写第一章 | 文风跑偏 |
| 没 Beat 就续写（beats 模式） | 跑题、浪费 token |
| 没生成概述就连写很多章 | 模型前文记忆弱、吃书 |
| 在 `characters.md` **中间删改** | 破坏只增不改、缓存失效 |
| 多浏览器标签同时写 | 单进程共享会话，互相覆盖 |
| 定稿只靠 AI **追加**不点 **替换** | 旧稿+新稿连在一起 |

## 6.3 备份与恢复

- 每次写入前自动备份到 `data/backups/`，每文件最多 **10 份**
- 手动恢复：从 `backups/` 复制到原路径
- **定期**把整个 `data/` 拷到外部存储
- 异常退出后写书对话可从 `session_autosave.json` 恢复；侧栏可点 **恢复写书记录**

## 6.4 新开一本（丢弃全部旧数据）

Web **无**一键重置。确定不要旧数据时：

1. **停掉** `web_app.py`（`Ctrl+C`）
2. （建议）备份整个 `data/` 到项目外
3. 删除 `data/` 文件夹，新建空 `data/`
4. 重新 `python web_app.py` → 自动创建模板文件
5. **概览** → **改书名** → 从 [阶段 A](#32-阶段-a搭地基开新书做一次) 重来

或 **复制整个 `novel_writer` 文件夹** 作为新书项目（旧书完整保留）。

**清空写书对话 ≠ 新开一本**：「清空」只删对话，不动 `world.md`、章节、plan。

## 6.5 常见问题 FAQ

**Q：API Key 红色横幅？**  
A：检查根目录 `.env`，Key 无多余空格/引号。

**Q：发送长时间无响应？**  
A：写书流式首字节 90s；有输出后空闲 180s。概述/检查总超时 120s。

**Q：全局设定改了没生效？**  
A：须点 **保存** 并通过确认框；不会自动保存。

**Q：想只重置对话？**  
A：**写书对话** → **清空**（章节保留）。

**Q：AI 误写入章节？**  
A：**撤销写入** 或 `data/backups/` 恢复。

**Q：Codex 勾了没用？**  
A：确认上下文模式为 `beats` 或 `codex`，且条目非空。

**Q：`Your request was blocked`（kie 不行、DeepSeek 行）？**  
A：重启 `web_app.py`；用 `http://127.0.0.1:8765` 打开；检查 `KIE_API_KEY`。

**Q：cache pill 能点吗？**  
A：只读。仅 kie 写书「发送」后更新。

**Q：如何减少 token？**  
A：Codex 为本章人物建条目并勾选，替代整份 `characters.md`。

**Q：人设慢慢变了？**  
A：每章更新 `char_dynamic`；锚点放 `char_static`；用人物检查 / 角色观察。

**Q：数字前后不一致？**  
A：立刻追加 `plot_threads_locked`；用提取细节；每 3–5 章连续性检查。
