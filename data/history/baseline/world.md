# 世界观与节拍设定

## 一、主线（贯穿全书 · 前期只露冰山一角）
女主为寻找失踪的妈妈而快穿。每个世界完成一个"任务"，攒够条件才能获取妈妈线索。

【母女悬念钩子】
原主病重 → 妈妈留话"我会治好你"后离开 → 原主病莫名好转，妈妈却消失。
- 妈妈用什么方式治好原主？她去了哪？是否也在穿越？
- 每个世界结算时只漏一点线索，吊到中后期揭开。前期女主自己也迷茫，不急着解。

## 二、任务规则（双任务结构）
每个世界两层任务：
- 【明线·主任务】完成原主的未了心愿。看得见、猜得到。
- 【暗线·隐藏任务】让某个关键角色"觉醒"——觉醒出自救/护己/护家的意识。
  - 呼应女主内核："只给愿意自救的人递梯子。"
  - 做不到隐藏任务 = 合格但不满分；做到 = 满分结算 + 更多妈妈线索。
  - 女主不一定知道隐藏任务的存在，靠她自己悟。

## 三、失败惩罚
任务失败 → 掉进"惩罚世界"。
（具体不急着展开，前期只需让女主和读者知道"搞砸有代价"，营造紧张感。）

## 四、旧世界回响机制（防女主冷血感）
- 女主不主动回头惦记旧世界男主，保持爽文向前推的节奏。
- 但每个旧男主留一个"她真的记得"的瞬间：结算时一行残影，或新世界某个似曾相识的细节让她心里咯噔一下，随即放下。
- 情感重量可调：偏甜多给回响，偏爽少给。第一个世界建议给一个。

## 五、第一个世界：古代乱世守护（宅斗壳 · 求存核）

【世界定位】
古代宅斗是壳，内核是"乱世求存 + 守护"。格局从后宅拉开到世道。

【女主身份】
- 原生家庭：商贾（有钱，能调资源）
- 现家庭：当官（不高不低，有信息和人脉，但不够硬）
- 核心处境："想护却护不动"——有钱有路子，但乱世不够硬，留足施展空间。

【家庭群像】
姐姐、几个弟弟、"新千金"——都团结，各有亮点。
- 这是暗线"觉醒"任务的土壤。
- 写作提醒：每个家人给一个记忆点（口头禅/小本事/软肋），别写成背景板。

【男主·憨憨帝王】
- 当前身份：想来女主城市打拼的普通人，读过书但认字不多，有肉眼可见的高光点（所以日后能聚人）。
- 真实身份：未来开疆拓土的开国帝王——被局势逼出来的。
- 反差：憨是真性情/保护色，帝王手腕是被逼出来的。
- 女主【不知道】他是未来真龙。

【核心爽点引擎·信息差】
女主务实地想"乱世怎么活、怎么护住这家人" → 凭直觉押注/帮了那个憨憨男人 → 她【以为】只是做件"能做的小事" → 他却是未来开国帝王 → 她无心插柳的每一步，回头都成了从龙之功。
→ "女主不知道自己攻略的是真龙" = 最大爽点+喜剧来源。

【明暗线咬合】
明线：守护家人
暗线：让某个原本软弱的家人觉醒护家意识
→ 女主递梯子，能不能爬上来靠他们自己。

## 六、旧日主线·真相线（到本世界结束时才可能被触发）
- 原主在原剧情里怎么死的？——稀里糊涂死于战乱，觉得"自己连一点帮助都做不到"。
- 原主心愿——变得有力量去守护，哪怕只做到一点点。
- 原剧情是什么？男主是皇帝这件事原主完全不知道。真相只在本世界结算时揭露一点点。
- 女主也全程不知道。读者知道。信息差保留到最后一刻。
